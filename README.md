# Анализатор ПУ · ТП

Выявление признаков безучётного потребления по помесячным выгрузкам ПУ:
рейтинг риска (алгоритмы S1–S14), тепловая карта, баланс ТП со сценариями,
интерактивная калибровка чувствительности, потолок недоучёта по диапазону
разрешённой мощности (0,22 / 0,4 кВ).

Всё приложение — один файл `index.html`, анализ выполняется в браузере:
выгрузки .xlsx/.csv НЕ покидают компьютер пользователя. Сервер (FastAPI)
только раздаёт статику. Библиотека чтения Excel (`static/xlsx.full.min.js`)
лежит локально — интернет странице не нужен.

Деплой: Amvera Cloud (`amvera.yml`, python 3.12, порт 80). После пуша в
`main` нажать «Пересобрать» в панели Amvera.
